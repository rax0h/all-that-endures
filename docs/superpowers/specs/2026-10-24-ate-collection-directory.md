# Collection namespace directory

Build an inactive complete directory of the visible lazy collection namespaces in one owned, fully audited SQLite snapshot. This closes the source-completeness gap between independent per-namespace constructors and a global orders root. It does not establish the separate save-head namespace inventory (which includes ordinary/event namespaces), allocator/target inventory, topology, successor directory publication, complete manifests or World admission.

Use the existing exact-byte OrderedSeekMap keyed by UTF-8 namespace, with immutable, generation-independent descriptor bodies binding namespace, declared state, member count, next ordinal and the collection order root. The outer certificate binds store, codec and generation. Reuse the existing collection constructor after factoring its already-audited root construction into a private helper; no second full audit per namespace. Persist per-namespace construction authority and descriptor bodies in the same transaction. Never repair a divergent existing descriptor/root row.

Chosen approach: a global ordered directory with content-addressed descriptor bodies. A directory of generation-dependent certificate hashes would rewrite every namespace at each generation; a flat tuple would make bounded lookup/page proportional to all namespaces. Neither fits later incremental publication.

Public APIs: bootstrap_collection_directory(store,pin,*,max_metadata_bytes=1048576) returns (CollectionDirectoryCertificate,expected). read_collection_namespace(store,pin,certificate,expected,namespace,*,max_metadata_bytes=1048576) returns a (CollectionCertificate,expected) pair or None after proving physical absence. read_collection_namespaces(...,after=None,limit=128,max_metadata_bytes=1048576) returns CollectionNamespacePage(entries,next_after), with pairs in entries and an opaque UTF-8 byte cursor. Returned collection authorities rebind generation without changing descriptor bodies. Existing read_collection_page validates actual selected order rows.

Require mandatory external 32-byte expected authority, closed codec, current/previous live pin, owned snapshot policy and checked schemas/indexes. Namespace and cursor byte lengths are at most4096; page size is1..128. Guard types/lengths in SQL before transfer. Descriptor body is fixed61 bytes (tag plus three counters and root digest), and always denotes a declared collection. Complete explicit construction may scale with archive size; bounded reads must transfer no payload bodies and make only selected indexed namespace probes. No clean-node cache, history collection, alternate writer or synthetic manifest roots.

Reject corrupt/missing descriptors/nodes, forged expected/context, altered actual counters, missing selected namespace, arbitrary transactions, shadow tables/triggers, oversized fields and codec hooks. A selected absence checks actual namespace state too. Unselected physical surplus remains full audit work, never a claim of bounded global corruption detection.

Review-driven clarification: before any inherited metadata read, validate TEMP resolution and exact base table DDL from trusted P1_DDL/P4_DDL. Absence additionally requires no order/version predecessor row with valid_from<=pin: namespaces never become undeclared after introduction, so even expired orphan predecessors are invalid. Two explicitly constructed, exact-validated(namespace,valid_from) indexes bound those probes while skipping arbitrarily many future-only rows at an old pin. This does not broaden detection of unselected surplus.
