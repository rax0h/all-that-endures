Reading many independent existing backings produces publisher lease updates.
These are already authenticated before every manifest publication, but then
consume the value/tail/insertion validators' unrelated 512-row shape budgets.
A small supported edit can consequently trigger two full World audits.

Reuse that existing lease validation to identify a finite set of existing,
nondeleted, schema-1, nonreinserted dependency updates with unchanged kind and
canonical empty memberships. Charge both old and new bytes, keys and namespaces
against an independent 4 MiB / 4,096-row budget. Over-budget updates retain the
original checked fallback. Fresh/deleted/structurally changed dependency rows
remain in the semantic transition and retain existing backing checks.

Only semantic classification receives the reduced row tuple. The frozen
transaction, content/inventory proofs, actual dependency rows, publisher-token
ownership checks and recovery retain the complete original delta. Preserve the
existing 512-row and 4 MiB semantic limits. No second authority or transaction.

Alternatives: raising the existing cap does not establish new semantic coverage;
omitting dependency publication breaks borrowed proxy lifetime. Neither is used.
This finite component does not certify a full simulated year's remaining
sequence, map growth or ownership changes, or mature-world target performance.
