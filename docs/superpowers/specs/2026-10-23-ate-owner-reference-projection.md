# Checked physical-owner reference projections

Continue the approved incremental-proof architecture after accepted CI39961497870. This component joins actual content bytes to complete committed owner placements for existing AUXILIARY_OWNER_FAMILIES. It does not provide complete World topology, owner catalog/radix agreement, links, retirement, target existence, manifests, publication or admission. No World activation/main merge/endurance.

Approaches: a generic object-graph walker risks inventing a competing ownership rule; extending the existing physical history adapters preserves permanent sequence IDs, key-side references, record fields and exact membership rules. Choose adapter reuse. This is the implementer's choice within the authorized architecture. Ordinary World owners and overwritten ordinary payloads remain gated.

New persistence_proof_projection.py exposes frozen RawOwnerProjection(source:RawVersion|None,reference_count:int) and read_owner_projection(store,pin,version_certificate,expected_version,occurrence_certificate,expected_occurrence,*,max_bytes=1048576,max_references=4096,max_metadata_bytes=1048576). Both external authorities mandatory. Occurrence scope must be exact OwnerScope in one of five registered physical families. Store codec must be exact WorldCodec with supported version; custom codecs require their own checked path.

One owned guarded snapshot covers both readers, exact retained pin and physical allocator. Before inherited head decoding, validate all four guarded head blobs with the same closed storage codec permitting standard metadata list/dict/set containers but no native mutable records/envelopes. Reject instance codec hooks as well as subclasses. Normalize delegated body/metadata/field budgets to ProjectionProofBudgetError and schema/codec encoding failures to StoreIntegrityError. Require actual canonical/cached lazy_record_interval plus occurrence/state interval indexes; no legacy fallback or hidden construction. Reuse read_version_bytes and read_occurrence_seek_page, preserving their actual fetched checksum/root/overlap/missing and metadata/body/field budget checks. Authenticate both certificate commitments before source work. Never admit unselected surplus; full inventory audit remains required.

Decode only the selected bounded source, memberships and owner key through an internal closed codec borrowing WorldCodec's existing tags. Allow immutable TypedCodec primitives, tuples/frozensets, core.Ref/Layer and the four existing typed reference tags. Reject native mutable records, lists/dicts/sets and frozen/event envelopes before restoration. No caller codec decode hooks, child/body lookup, or World object restoration. Guard parsed typed-node inventory to32768 nodes/depth64; payload bytes remain the pre-transfer bound. Malformed codec/schema failures become StoreIntegrityError, budget excess ProjectionProofBudgetError. JSON parsing itself is bounded by byte budget, not a claim of a tight universal2MiB allocation cap.

Owner keys, source schema/memberships/payload and reference paths use the existing adapter.validate_source/validate_path/reference_placements contracts. Owner incarnation and every projected target must be strictly below the certificate allocator. Enforce source key byte length<=4096, source body budget1..64MiB, references1..4096 (zero references valid), metadata1..64MiB. A physically absent source is allowed only with an exact empty committed owner root; orphan selected placements fail. A present zero-reference body must match an exact empty root.

Sort projected (encoded path,incarnation) pairs within the explicit changed-owner budget; reject duplicate paths and overbudget paths. Stream accepted occurrence pages<=128 and compare all actual root-selected entries exactly, including count/end. Never gather unrelated owners or target bodies. Return the original RawVersion bytes unchanged plus reference_count; parsed objects are private disposable storage values. The two certificates must share store/generation/codec and exact pin; nested checked snapshots allowed, arbitrary borrowed transactions rejected, errors leave no owned transaction open.

Tests: literal reference/path vectors for every adapter; all reference tag kinds including Ref/frozenset/key-side NaN references and signed float/NaN preservation; mismatch with independently valid content and occurrence certificates (missing/extra/replacement), allocator bounds, absent body/orphan root, malformed/disallowed source, source/field/depth/node/reference budgets, certificate/context/capability/transaction faults, actual fetched corruption, current/previous exact reads after reassignment/delete. Fixed changed owner with1k/10k/100k unrelated physical history bodies must read/check exactly one selected source and no target/archive payloads. Construction and changed-set work remain separate. No latency-target claim.
