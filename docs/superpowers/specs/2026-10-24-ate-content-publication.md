# Version and event content publication

Construct production version-content and immutable event-segment roots from an explicit full physical audit. Bind exact current lazy version bytes/memberships/schema/start generation, and exact segment bytes/ID bounds/count/codec/creation generation. Preserve existing positive segment hashes and support the store's legal zero-element segments. Do not change opaque representation or World semantics.

An externally accepted ContentCertificate binds store, codec, generation and the two roots. Closed raw readers resolve exact version certificates into the existing reader and authenticate selected segment bytes; absent leaves authenticate absence. Current/previous live pins only, guarded source types/byte lengths, explicit body/metadata budgets, canonical schemas and no DB triggers. Bootstrap owns its transaction and never replaces an existing generation row. Full archive construction stays outside ordinary operation timers.

One unified opt-in save requires accepted content, ordinary-record and scope authorities. It composes all three through the existing LazyRecordStore.commit transaction. Authenticate affected actual old version content against the accepted parent before inherited writes, with scope guards before preliminary reads and again inside the writer. At final staging compare actual successor version/segment bytes to prepared input, update sorted changed keys, and bind the existing exact writer pin/token/receipt. Preserve bounded cleanup until staging completes. All component roots, bodies, head and receipt commit together. No-op/conflict/lost-ack recovery keep existing semantics and never replay.

This closes actual production version and event content slots and unifies currently implemented components. Complete topology/target proofs, collection order/namespace inventory, the full seven-root generation manifest, format activation, writer fencing and canonical World admission remain explicit prerequisites. No World path switch, alternate publisher/registry, history deletion, clock reset, collection or endurance. Point-save measurements are not full World/year acceptance.
