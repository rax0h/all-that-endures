Close the production-construction gap for root-selected owner/group placements and lazy query membership. Construct all nonempty scopes from the same fully audited physical snapshot, and preserve their roots through actual existing save transactions. A scope descriptor binds its exact domain and ordered root digest/count; it deliberately excludes generation and allocator. Four immutable directory roots bind owner placements, group placements, query membership and the reverse query set per owner. The fourth root is necessary to reject coherent removal of old membership rows without scanning all query scopes. The enclosing certificate binds store, codec, generation and allocator. Thus metadata-only generations and allocator advances reuse unchanged directory roots.

Explicit bootstrap owns BEGIN IMMEDIATE and full verify_all, with closed codecs, current pin, source metadata byte/type guards, and no reuse/repair of an existing generation row. Full archive audit/construction remains outside normal timers. An absent directory entry authenticates an empty scope. Authenticate affected old members against accepted roots, verify new rows match the prepared transition, spool deltas in SQLite and update only touched scopes/directories. Publish data, head, receipt, descriptors and successor directory roots in the one existing commit transaction. Reuse the existing read-only SQL callback guard and data_version parent epoch. Optional ordinary-record authority composes both component publications in this transaction. Exact existing recovery must bind parent, writer pin and token without replay.
