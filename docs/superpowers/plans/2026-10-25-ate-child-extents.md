> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans inline.

**Goal:** Prove complete list/map/set child extents and existing integer/lineage-pair incoming member policies without scanning unrelated child parents.
**Architecture:** Extend the existing scope publisher with an explicitly constructed fifth physical child-locator directory, grouped by parent incarnation across the five registered auxiliary physical families. Four-root certificates retain their original commitment encoding and remain readable; only explicit include_children=True construction creates version2 five-root certificates. The same existing scope writer updates the fifth root from actual prepared/version source changes in its existing transaction. Default four-root saves never invent child authority. A new inactive raw extent reader composes accepted target/incoming bodies with the child inventory, exact list page shapes, complete scalar entries/counts/ordinals, and actual member counts checked against the existing type witness. Existing incoming integer/lineage-pair policies come from the runtime's existing definitions, centralized without changing behavior.
**Tech Stack:** Existing Python/SQLite immutable maps, disk staging, pytest.
