Certification follows the existing runtime one-hop contract: every distinct frozen or NaN dependency encountered in values is resolved under the same accepted content/scope/inventory authority and owned snapshot. It checks target kind, allocation/non-retirement and physical live placement, shares the aggregate/per-source byte limits, and caches only operation-local dependency results.
