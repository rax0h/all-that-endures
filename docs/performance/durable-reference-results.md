# Durable selected reference proofs

This package persists checked semantics for an explicit bounded selection of directed raw reference graphs. `persistence_proof_reference.py` constructs generation-independent descriptors with a graph digest, target/edge counts, immutable-target truth and complete dependency bindings. The immutable selected-root map and generation certificate bind those descriptors to accepted content, six-root scope, head inventory and retained ordinary-record authorities. Returned facts admit no native objects.

Source dependencies include exact positive and absent version keys, ordinary bodies, all group-verifier catalog/radix/link/retirement reads, and complete group/owner/query/child/sequence scope roots. New competing backings, children and incoming owners cannot hide behind an unchanged list of old physical keys. Allocator changes conservatively force revalidation. Source revisions remain dependencies even when replacing a body with identical bytes.

`persistence_proof_reference_publish.py` runs after the existing inventory/component stages inside the existing writer transaction. It compares authenticated dependency paths, rebuilds changed selected closures with the existing shared work budgets, and reuses unchanged descriptor hashes. Root changes, component roots, exact parent/writer/token and the existing recovery receipt commit together. Before-commit rollback and after-commit acknowledgement loss use the same existing protocol; recovery checks all component bindings and supports fresh reopen. Existing public inventory APIs remain compatible and reject private request injection.

Construction is explicit and may walk the selected graph. Ordinary fact lookup reads descriptor/root metadata only. Reuse avoids graph bodies; rebuilding an affected graph remains a bounded full selected-closure check, not yet a per-node semantic update. Limits are128 selected roots,128 targets per rebuilt closure,8192 dependency bindings per descriptor,1 MiB per descriptor and4 MiB aggregate descriptor bytes per operation (parent plus replacement during publication). The existing closure limits on edges, incoming members, children, values and raw source bytes remain enforced. Crossing a limit fails closed; there is no implicit global traversal.

This is a retained semantic fact, not a physical scrub. Fetched bytes still require their accepted content checks. The selected inventory is fixed at construction; it does not prove global backing/owner liveness, unindexed incoming owners, complete World field domains or whole-World topology. Unsupported frozen-certification cycles remain rejected. No complete generation manifest, upgrade, old-writer fence, native World path, canonical alias admission or mature performance acceptance is enabled.

The stable remaining stages are unchanged: finish durable production/publication, integrate World/upgrades/recovery, then demonstrate end-to-end correctness and measured performance. This is the first of the estimated two durable-production CI milestones. No additional long CI was run between implementation tasks.
