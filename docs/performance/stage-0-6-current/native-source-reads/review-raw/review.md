| R1 | Important | Native read capability is ambient. A real read-only before_commit callback sees world.year (0,1) before that child's acceptance, then its exception rolls the row back; outside the operation the returned value never existed in any accepted child. A separately installed real NativeWriteGuard also disables proof joining for forged (0,999). | R2 | Important | The two ordinary epoch guards run before SQLite pins the snapshot. An independent real update between check and BEGIN lets the first read succeed and the next detect invalidation. Validate the live epoch within the observed snapshot, with a race test. probe.py / probe.log. |
| R3 | Important | The outer legacy lazy snapshot reads head/pin/receipt/attempt bodies before the new guard; the nested adapter has no operational metadata preflight. After an untracked update a 4 MiB save_head field reaches Python before the first error; unchecked operational fetchall is likewise exposed. Use bounded operational checks before the earliest inherited metadata fetch/decoder. probe.py / probe.log. |
| R4 | Important | The row's SQL CASE expressions authorize transfer one field at a time, so a large otherwise in-budget body is transferred even when the row is already unambiguously invalid. A malformed record_schema transferred 4 MiB before raising. Version and event have analogous independent metadata/body predicates, as do invalid enumerated typed keys. Reject fixed scalar/type/length/budget failures before transferring source bodies, including event IDs. probe.py / probe.log. |
| R5 | Important | The native public CheckedVersion exposes valid_to, which is not in the immutable content preimage. A recomputed row checksum and forged closure at 13 on physical head 0 returns 13 to the caller. Reject impossible future closure before returning the native tuple. This need not change content preimages or expand relation scope. probe.py / probe.log. |
| R6 | Important | Nested snapshot borrowing ignores the outer checked generation. With a genuine retained generation-0 pin, an outer checked snapshot yielding 0 reads the current (0,1) ordinary row after the proof session committed generation 1. Require matching checked snapshot before borrowing; also preserve valid same-generation nesting. nesting.py / nesting.log. |
| R7 | Minor | The 1k/10k work test stores unrelated_body_reads=0, but only intercepts _source_version. An extra native event/ordinary payload fetch or direct query of segment bodies would not affect the reported zero. Instrument physical body selection across those source tables (or narrow the property name and add a distinct no-segment assertion), and report the actual observed work. |
| R8 | Minor | The adapter reconstructs version/segment checksums by rehashing a payload whose stored checksums were already read and verified. The existing native decoder then checks hashes again. For a version, fixed framing requires two original checksum passes and one map commitment; two further passes solely manufacture tuple fields immediately checked again by the legacy reader. Reuse validated original physical checksum fields so reconstruction need not hash up to 64 MiB per pass; leave the canonical decoder's defensive contract intact. |

The intentionally isolated content-corruption tests in R4 and R5 suppress the coarse epoch check as specified. The first 35 authors' tests passed: they do not exercise these paths.
