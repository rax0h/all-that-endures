# Canon and Open Questions

This file prevents implementation convenience from silently becoming lore or product canon.

## Locked direction

- Title: **All That Endures**.
- The game is 2.75D: real spatial 3D beneath a controlled illustrated-fantasy presentation.
- Each run can generate a different world before running history.
- The world has one primary connected Pangaea-like continent and the mapped world is the simulated/playable world.
- Geography is generated before history.
- Historical probability is not biased toward the player or narrative needs.
- Objective history cannot be fabricated by quests, rumors, lore or environmental-story systems.
- Most people have little or no magic; the setting must remain materially grounded.
- Rank progressively transforms body and mind and eventually can replace ordinary biological dependence with magical organization/sustenance.
- Higher-rank sustenance involves spirit coins; exact mechanics are unresolved.
- Procedural visual generation must remain at production art quality.
- Transparent isolated assets are authored with true alpha at source.

## Explicitly unresolved

- Exact world dimensions, topology parameters and travel-time targets.
- Pre-player history duration for the shipped game and whether it is configurable.
- Initial and present population scale.
- Exact rank names/order if not already ratified elsewhere for this project.
- Rank-by-rank consequences for lifespan, cognition, food, spirit-coin metabolism, sleep, respiration, organs, disease, healing, reproduction, perception, movement and injury.
- Population distribution of no Essence / Essence access / skill counts / ranks.
- Exact Essence and Awakening canon to import/ratify.
- Engine/runtime technology choice.
- Final camera numerical constraints.
- Final rendering/performance target hardware and budgets.
- Final asset counts and production staffing assumptions.
- Character-creation design.
- Exact playable species/peoples.
- Whether the world has moons/off-world reachable geography and when high rank makes it relevant.

## Rule

When implementation needs one of these values, expose a configurable assumption or request a canon decision. Do not bury a permanent lore decision in code.
