# All That Endures

**All That Endures** is a simulation-first fantasy role-playing game intended to become a full 3D, AAA-quality world that lives before the player arrives.

A world seed creates a single-continent physical world. Its geography, climate, ecology, resources and initial populations become the starting conditions for a long-horizon causal simulation. Civilizations, families, organizations, settlements, roads, buildings, artifacts, traditions, conflicts, discoveries, ruins, beliefs and legends emerge from that history. The player enters the resulting present and remains inside the same rules as everyone else.

The project is built around one central idea:

> **The interaction graph is the product.**

The world is not generated to serve a predetermined story. History creates reality; societies respond to it; people remember and misunderstand it; narrative exposes pressures and possibilities already present in the world.

## First implementation target

The first game-side milestone is the **Visual World Laboratory**: a deliberately bounded environment proving that simulation state can deterministically realize beautiful, historically layered terrain, settlement architecture, characters, ecology, weather, lighting and magic without lowering the art standard. The laboratory may use a constrained camera or 2.75D presentation where useful for iteration, but that is a prototype path rather than the final visual ceiling.

The long-term presentation target is a **full 3D, AAA-quality RPG**, supporting first- or third-person play and built so future Unreal Engine, neural-rendering and related graphics technology can realize the same underlying simulated truth at progressively higher fidelity.
