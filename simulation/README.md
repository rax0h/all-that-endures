# Simulation Foundation

The current verified long-horizon foundation establishes working contracts for persistent expeditions, material circulation/provenance, craft traditions, culture/memory feedback, millennium composition, explicit household demography, relevance-scaling equivalence, chronicle continuity, and enterprise/wealth/dynasty emergence and dissolution.

This foundation is **not the finished All That Endures world simulation**. The target architecture is defined in `docs/SIMULATION_ARCHITECTURE.md` and expands substantially into the World Causality Graph, cognition/creativity, embodied mind, weather/climate, World Pressure, preparedness/path dependence, world generation, rank ontology and the other domain interactions.
