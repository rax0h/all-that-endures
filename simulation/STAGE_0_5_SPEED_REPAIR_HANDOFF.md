## Implementation

The existing checked owner projection no longer rediscovers unchanged identity
groups for packed structural reconciliation. Pure eager scalar actions can
reconcile actual notified logical positions through the existing dirty journals;
captured generation, same-connection writes (`total_changes`) and external
SQLite commits (`data_version`) invalidate the projection. Actual mutable fields, native-backed records and structural changes
retain the full graph path. Mutation refreshes its selected affected group so a
warmed certificate cannot conceal raw authority corruption.

Scalar payload dirt still marks real publication owners but does not manufacture
another structural packed-list change. A pre-existing tracked-mutable-field
packing failure was also reproduced on the unchanged baseline and repaired with
the existing alias-preserving plain-value conversion and closed-record checking.
No format, gameplay, arithmetic, RNG, second registry or persisted authority was
introduced. New tests cover the clean-cache threshold, repeated appends, existing
and new scalar edits, shared cross-family records, trimmed private aliases,
mutable children, moves, duplicates/equal-distinct records and warmed corruption.
